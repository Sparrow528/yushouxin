# DPP 产品路演内容大纲

> 时间：2026年10月9日下午

## 一、开场：为什么是 DPP？为什么是现在？

### 1.1 法规背景（30秒讲清楚）
- **欧盟电池法规 (EU) 2023/1542** 已正式生效
- **2027年2月18日起**：电动汽车电池、E-bike电池、>2kWh工业电池必须持有**电池护照**才能在欧盟销售
- 电池护照包含 **71个数据点**（Annex XIII），涵盖碳足迹、回收料比例、供应链尽职调查等
- 中国是全球最大电池生产国，**不合规 = 失去欧盟市场**

### 1.2 市场格局（蓝海机会）
- **供不应求**：国内能做DPP合规服务的机构极少，客户主动找上门
- **定价权在手**：市场空白期，没有价格战，按价值定价
- **时间窗口**：距离强制实施仅剩4个多月，企业急需合规方案

## 二、我们做什么？（一句话定位）

> **帮助中国电池及含电池产品企业，完成欧盟电池法规的合规要求——从评估差距到护照上线到持续维护，提供一站式服务。**

## 三、服务体系全景（核心内容，重点讲）

### 客户旅程图
```
客户主动咨询 → ①差距评估 → ②数据建设 → ③注册上线 → ④年度托管
                 知道自己差什么   把数据补齐    护照上线     持续合规
```

### 3.1 ① 差距评估（1-2周）
**告诉客户"差什么"**

- **服务内容**：
  - 71个数据点逐项核查
  - 32项证据链审查
  - 六维加权评级（A1-F4维度）
  - 出具整改优先级路线图
  
- **三档定价**：
  - 基础版 ¥8万-15万（1种电池，≤10 SKU）
  - 标准版 ¥20万-35万（多种电池，≤30 SKU）
  - 旗舰版 ¥50万-80万（不限SKU，含3个月整改辅导）

- **交付物**：差距评估报告 + 整改路线图 + 下一步服务建议书

### 3.2 ② 数据建设（4-8周）
**帮客户"补数据"**

- **服务内容**：
  - 35个核心字段采集体系搭建
  - 供应商数据催收打包
  - 三级核验机制（L1/L2/L3）
  - 数据手册生成
  
- **两档定价**：
  - 标准版 ¥20万-30万
  - 旗舰版 ¥30万-45万（含供应商采集打包）

- **交付物**：数据手册 + 数据合规性报告 + 数据维护计划

### 3.4 ③ 注册上线（12-16周）
**帮客户"上线"**

- **服务内容**：
  - eIDAS身份认证
  - 欧盟授权代表（欧代）安排
  - 注册中心申报
  - 8步上线流程
  
- **两档定价**：
  - 标准版 ¥30万-45万
  - 旗舰版 ¥45万-60万
  - 另加第三方费用 €6,500-21,000（欧代+注册中心）

- **交付物**：电池护照上线 + 注册确认文件

### 3.5 ④ 年度托管（持续）
**持续合规，年费制**

- **三大核心服务**：
  - 数据维护（定期更新动态数据）
  - 法规跟踪（每日扫描，季度简报）
  - 应急支持（监管查验1小时响应）

- **三档定价**：
  - 基础版 ¥8万-20万/年（半年更新+邮件响应）
  - 标准版 ¥20万-35万/年（季度更新+工作日响应）
  - 旗舰版 ¥50万+/年（月度更新+随时响应）

## 四、商业模式亮点

### 4.1 单客户价值
- **首年最大价值：¥66万-235万**（①+②+③+④旗舰版合计）
- 年度托管形成**持续收入**
- 客户转介绍带来**裂变增长**

### 4.2 定价策略
- **空白期红利**：市场无竞争者，客户主动找上门，按价值定价
- **三档分层**：覆盖不同规模客户需求
- **年费续费**：确保持续现金流

### 4.3 服务壁垒
- 18年财税合规经验
- 欧盟法规深度解读能力
- 全流程一站式服务（评估→建设→上线→托管）
- 配套工具箱（35个专业模板）

## 八、Q&A 准备

### 常见问题预判：
1. **"客户为什么不自己找欧盟机构做？"**
   - 语言障碍 + 法规理解门槛
   - 我们提供中文全流程服务 + 本土化支持
   - 价格其实更有优势（欧盟机构收费更高）
   
2. **"2027年2月来不及怎么办？"**
   - 差距评估可以1-2周完成，快速启动
   - 可以先完成①②，③注册上线可以分批进行
   - 越早启动越主动

3. **"这个业务能持续多久？"**
   - 法规持续更新，合规是长期需求
   - 年度托管是持续性收入
   - 可拓展到其他品类DPP

4. **"其他机构进来了怎么办？"**
   - 我们有先发优势 + 35个标准化工具箱
   - 18年财税合规经验形成专业壁垒
   - 年度托管绑定客户，后来者难以切入
