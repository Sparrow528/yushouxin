拆解逻辑：准备物的四层展开

反推规划已确定"10项服务→需要什么准备"的框架；本文件把每个准备物继续往下拆：它是什么（内容结构）→ 怎么做（编制路径）→ 谁来做（三角分工）→ 怎么算做完（验收标准）。

拆解原则：① 电池行业版本优先做（2027.2.18死线最近）；② 每份模板先用1个种子客户跑通再定稿；③ P0 = 获客前必须有，P1 = 首单签约前必须有，P2 = 交付过程中完善即可。

核心层 4 项服务的准备内容拆解

核心层是首单利润来源，准备要求最高。以下每项服务拆到具体模板结构与编制路径。

服务① DPP差距评估（敲门砖，3–5人天） P0 最优先
交付物：《DPP差距评估报告》（含整改清单与时间表）——低门槛建立信任，评估费可抵扣主单

准备物 1：《差距评估核查清单》 P0

  • 基础版结构：ESPR通用要求核查（数据载体、唯一标识、注册状态、标签要求）+ 行业专项核查（数据项逐条对照）
  • 电池版（最先做）：对照电池法规附件，覆盖材料构成、碳足迹声明、供应链尽职调查、维修回收、电池护照字段五大模块，逐条列"要求原文→企业现状→差距判断"
  • 后续版本：纺织版、电子电器版、家具版、建材/铝版——结构同电池版，替换行业数据项
  • 编制路径：先生主笔电池版 → 用种子客户实测修订 → 再复制到其他行业（每版约3–5天）
负责人：先生 ｜ 验收标准：拿一家真实电池企业数据走一遍，每个核查项都能明确判"合规/缺失/不适用"

准备物 2：《差距评估报告》模板 P0

  • 章节结构：企业概况 → SKU核查结果 → 差距分析（按严重度排序）→ 风险评级 → 整改清单（每项标注工作量与建议时间）→ 下一步行动建议
  • 风险评级模型：红/黄/绿三档；评分维度=数据完整性（BOM/碳/供应链）+ 时间紧迫度（行业死线距离）+ 注册状态 + 供应链成熟度，四个维度加权打分
  • 关键设计：整改清单必须落到"可以报价"——每项差距对应到我们哪项服务，报告本身就是销售工具
负责人：先生 ｜ 验收标准：报告输出后客户能直接看懂"我差什么、要花多少时间、先做哪件事"

准备物 3：评估操作SOP + 首访访谈提纲 P1

  • 访谈提纲：现场访谈问题清单（SKU规模、欧盟客户构成、现有CE/ISO、供应链层级、内部谁管合规）——半结构化，30分钟能问完
  • 操作流程：首访访谈（0.5天）→ 资料分析（1天）→ 现场核查（0.5–1天）→ 报告输出（1天）→ 讲解汇报（0.5天）
负责人：先生，市场合伙人陪同首访
服务③ DPP数据规划与手册（5–8人天） P0 最优先
交付物：《DPP数据手册》（按SKU）+ 数据项采集台账模板

准备物 1：各行业《DPP数据项标准清单》 P0

  • 清单结构：每个数据项一行——字段名称 / 法规依据条款 / 必填或选填 / 数据来源（客户提供/供应商收集/检测机构出具/自行计算） / 更新频率
  • 电池版优先：覆盖材料构成（有害物质、关键原材料占比）、碳足迹（生产阶段排放）、供应链（原产地、供应商识别）、性能与耐久、维修与回收、电池护照唯一标识等模块
  • 数据项分级：必填（法案强制）/ 选填（法规允许但有客户要求）/ 增值（提升数据看板价值）——分级决定采集优先级
负责人：先生主笔法规部分，IT合伙人协助字段标准化（与后续系统对齐）

准备物 2：《DPP数据手册》编制模板 P0

  • 按SKU组织：一个SKU一张数据卡——产品基本信息 / 数据项清单（沿用标准清单结构）/ 每项数据的责任人 / 采集路径 / 当前状态（已齐/收集中/缺失）
  • 台账联动：手册与采集台账字段一一对应，手册是目标态，台账是过程态
  • 方法论说明页：给客户老板看的"一页纸"——为什么每项数据都要、缺了会怎样
负责人：先生设计模板，交付顾问执行填写 ｜ 验收标准：种子客户的1个SKU手册全字段填满无遗漏

准备物 3：数据采集台账模板（Excel） P1

  • 台账字段：数据项 / 所属SKU / 责任人 / 来源方（客户自填/供应商A/检测机构） / 下发日期 / 回收截止 / 当前状态 / 核验结果 / 备注
  • 使用规则：每周更新，作为项目周报依据；台账完成率直接挂钩项目进度
负责人：交付顾问（招到后）维护，先生审核
服务④ 供应商数据收集辅导（6–10人天） P0 最优先
交付物：供应商数据回收台账 + 合格数据包（覆盖2–3级供应链）

准备物 1：供应商问卷模板（中英双语） P0

  • 问卷模块：供应商基本信息 / 供货材料构成（名称、占比、来源地）/ 有害物质声明 / 碳数据（有则填，无则标注"暂无"）/ 现有认证（ISO/REACH/RoHS等）/ 联系人与签字确认
  • 分版本：原材料供应商版（重材料数据）/ 元器件供应商版（重成分与认证）/ 加工商版（重工艺与能耗）
  • 双语说明：每题附英文对照与填写示例，降低供应商填写门槛——供应商配合度是最大变量，问卷体验决定回收率
负责人：先生编写中文版，英文翻译外包或AI初翻+人工校对

准备物 2：催收SOP与话术包 P1

  • 催收节奏：问卷下发 → 第7天邮件提醒 → 第14天电话跟进 → 第21天升级客户协调（客户向供应商施压）→ 第30天仍未回收则列入缺失项整改
  • 话术包：给客户的催收协调函模板（客户发给供应商）、给供应商的解释函（为什么要这些数据、不交的后果）
负责人：交付顾问执行，先生设计机制

准备物 3：数据核验标准 P1

  • 三级核验：完整性（必填字段齐全）→ 合理性（数据逻辑自洽，如材料占比加总100%）→ 佐证性（认证证书可查、检测报告在有效期内）
  • 不合格处理：退回重填话术 + 常见错误FAQ
负责人：先生定标准，交付顾问执行
服务⑤ 欧盟注册中心注册辅导（4–6人天） P0 最优先
交付物：注册账户 + 注册确认函 + 清关核验指引

准备物 1：Registry平台操作手册（团队先自己跑通） P0

  • 跑通优先：注册中心2026.7.20已上线——团队必须先用自己的主体（或欧代合作方配合）实际注册一遍，不能只看文档
  • 手册内容：注册流程步骤图（账户开立→主体信息→产品档案→数据字段→提交通道）、每步所需材料清单、常见退回原因与规避方法、审核周期实测记录
  • 动态更新机制：平台规则会持续更新，手册标注版本号与更新日期，指定专人跟踪
负责人：先生+IT合伙人（IT合伙人负责API与数据字段部分）｜ 验收标准：完整走通一个测试注册流程

准备物 2：客户侧前置条件指引 P0

  • eIDAS电子印章办理指引：合格信托服务提供商（QTSP）候选名单、办理所需材料、周期、费用区间——客户办理是注册的前置，指引要细到"照着办就行"
  • 欧盟授权代表签约指引：欧代的作用、选型要点（行业匹配、响应速度、费用）、签约注意事项
负责人：先生编写；欧代合作渠道见外部合作部分

准备物 3：《清关核验指引》文档 P1

  • 内容：海关如何扫码核验DPP、哪些字段会被查验、核验失败常见原因、客户报关员应对口径
负责人：先生编写，首单客户交付时实测修订

引流层 2 项服务的准备内容拆解

服务② 合规自查工具（99元/次，标准化） P0 获客引擎
交付物：《企业DPP合规自查报告》（系统自动出具，含风险等级+待办清单）

准备物 1：问卷题库与评分算法 P0

  • 题库结构（15–20题，5–10分钟答完）：①行业（电池/纺织/电子/家具/建材/其他）②产品类别与SKU数量 ③是否含电池及电池类型 ④年出口欧盟额 ⑤欧盟客户占比 ⑥欧盟客户是否已发DPP/碳问卷 ⑦现有CE/ISO认证 ⑧BOM完整度自评 ⑨供应链层级数 ⑩内部是否有专人管合规
  • 评分算法：死线紧迫度（权重最高，电池行业直接加权）× 数据基础 × 认证基础 × 客户压力 → 输出红/黄/绿三档 + 三个最关键差距点
  • 报告结尾设计：固定引导位——"预约免费咨询，由顾问讲解报告"——直接接入核心层销售
负责人：先生设计题库与算法逻辑，IT合伙人技术实现

准备物 2：在线系统开发 P0

  • 前端：H5问卷页（手机端优先，微信可打开）、答题进度条、结果即时展示
  • 后端：评分引擎 + PDF报告自动生成 + 支付对接（99元）
  • 线索管理：每份报告自动进入线索池（行业/评分/联系方式），按红黄绿分级推送给市场合伙人跟进
  • MVP路径：第一版可以用问卷星/腾讯问卷+人工出报告过渡，同步开发正式版——获客不等人
负责人：IT合伙人主导开发 ｜ 验收标准：手机扫码→答题→支付→收到PDF报告全流程≤15分钟

准备物 3：《欧盟DPP合规明白纸》+ 图文微课 P1

  • 明白纸结构：是什么（一句话+一张图）→ 罚什么（卡关/丢客户/滞港费）→ 谁中招（行业死线表）→ 怎么办（三步走）→ 花多少钱（分档价格区间）
  • 微课：明白纸内容扩展成4–6节图文/音频课，9.9元定价，与99元自查工具形成价格阶梯
负责人：先生出内容框架，内容运营执行
免费科普内容（短视频/直播/公众号） P1 持续获客

准备物：内容日历与选题库 P1

  • 选题库（首批30条）：死线提醒类（"电池护照还剩X个月"）/ 后果警示类（"货卡在港口的滞箱费怎么算"）/ 科普类（"DPP扫出来是什么"）/ 案例类（客户问卷长什么样）/ 对比类（"CE认证踩过的坑，DPP会不会重来一遍"）
  • 内容日历：每周2–3条短视频 + 每月1场直播（死线倒计时主题），关键节点（法案生效、行业大事件）加发
  • 统一话术库：沿用方案里的"老张老李"口语化风格，所有内容统一从《切入话术》派生，保证口径一致
负责人：市场合伙人统筹选题与分发，内容运营/外包执行剪辑

增值层与绑定层的准备内容拆解

服务⑥ 碳足迹数据对接（5–8人天） P1 增值项
交付物：碳足迹数据对接方案 + 核算机构对接记录

准备物 1：LCA机构合作 + 碳字段映射表 P1

  • 机构签约（外部合作）：筛选并签约2–3家碳足迹核算机构，谈定转介分成或联合交付模式——我们自己不算碳，做"数据翻译与对接"
  • 《碳足迹-DPP字段映射表》：核算报告的哪些输出字段对应DPP碳数据项、格式如何转换、由谁上传——这张表是与LCA机构协作的接口标准
  • 知识储备：ISO 14067 / PEF方法论基础认知（能看懂核算报告、能向客户解释口径差异即可，不要求自己建模）

服务⑦ CE+DPP衔接辅导（4–7人天） P1 差异化主项

负责人：先生主笔，优先以航大淼盾案例实测
服务⑧ 企业内训 ｜ 服务⑨ 经销商导入辅导 P2 按单准备

服务⑩ 数据托管年度维护（6–15人天/年） P1 续费引擎

准备物 1：法规跟踪机制与简报模板 P1

开工节奏：三条线并行

准备不分先后串行，按"知识线 / 工具线 / 合作线"三线并行，两周内形成获客能力。

知识线
