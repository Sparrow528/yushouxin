📋 各阶段操作要点

1
启动评估
Week 1-2

目标：建立项目基线，了解客户组织架构和电池产品组合

  • 签署服务协议 — 确认服务范围（电池类型、SKU数量、供应链复杂度）
  • 发放 01_核查清单 — 指导客户内部6个维度负责人分别填写
  • 召开启动会 — 明确项目时间表、联系人、资料提交截止日
  • 收集基础资料 — 营业执照、电池产品技术规格书、现有认证清单
质量关口：核查清单回收率≥80%（即26/32项已填写）方可进入下一阶段

配套工具：01_DPP差距评估核查清单_电池版.xlsx

2
差距分析
Week 2-3

目标：量化合规差距，确定整改优先级

  • 逐项评分 — 对32项逐一判定：达标(2分) / 部分达标(1分) / 缺失(0分)
  • 计算维度得分 — 各维度得分率 = 实际得分 / 满分 × 100%
  • 识别TOP5差距 — 按影响度和紧急度排序，标记「阻塞项」vs「可并行项」
  • 填写评估报告 — 使用 02_DPP差距评估报告_模板.docx
  • 向客户汇报 — 召开差距分析会，确认整改路线图
关键：TOP5中如有「阻塞项」（如缺少eIDAS证书、无欧代协议），必须立即启动，不可等待其他项完成

配套工具：02_DPP差距评估报告_模板.docx

3
数据采集
Week 3-8

目标：按Annex XIII要求完成38项标准数据采集

  • 下发数据项清单 — 使用 03_DPP数据项标准清单_电池版.xlsx 明确每项要求
  • 指导填写数据手册 — 04_DPP数据手册模板.xlsx 含3个Sheet
  • 发放供应商问卷 — 05_供应商数据问卷_中英双语.docx 针对上游供应商
  • 数据回收与校验 — 逐项检查完整性、格式合规性、逻辑一致性
  • 缺失项追补 — 发出催办通知，必要时安排电话/视频跟进
质量关口：38项数据完整率≥90%、供应商回函率≥80%方可进入注册阶段
4
整改辅导
Week 4-12

目标：逐项关闭评估中识别的合规差距

  • 执行整改方案 — 按评估报告中的路线图逐项推进
  • 协助获取认证 — 如客户缺少UN38.3、IEC 62133等认证，推荐检测实验室
  • 完善供应链数据 — 对拒绝配合的供应商启动替代方案（第三方审计报告）
  • IT系统对接 — 协助客户选择DPP载体方案（二维码/RFID/NFC）
  • 建立管理流程 — 制定数据更新SOP、异常处理流程
并行原则：阶段3（数据采集）和阶段4（整改辅导）高度重叠，应并行推进
5
注册上线
Week 8-16

目标：完成eIDAS认证和EU DPP Registry注册

  • 办理eIDAS证书 — 参照 06_eIDAS与欧代办理指引.docx
  • 签署欧代协议 — 选定EU Authorised Representative
  • 技术测试 — 在EU Registry沙箱环境测试数据提交
  • 正式提交 — 通过EU Registry提交DPP数据包
  • 验证上线 — 确认DPP可被终端用户扫码访问
里程碑：DPP注册成功 = 客户合规义务达成，可合法在EU市场销售
6
持续维护
Ongoing

目标：确保持续合规，应对法规更新

  • 年度数据更新（电池性能衰减数据、回收成分比例）
  • 法规变更监控（欧盟委托法案更新）
  • 供应链变更同步（新增/替换供应商数据更新）
  • 产品变更通知（新材料、新工艺触发DPP更新）
  • 年度合规复核报告

📄 2.2 评估报告填写指南

文件：02_DPP差距评估报告_模板.docx

报告结构及填写说明

  1. 封面页
    • 填写：客户名称、评估日期、评估人员、报告编号
    • 报告编号格式：SX-DPP-YYYY-NNN（如 SX-DPP-2026-001）
    • 添加：Logo、客户Logo（如有）
  2. 摘要表（Summary Table）
    • 6维度得分一览表，每维度填入：实际得分/满分、得分率、评级
    • 总体得分率 = 各维度得分之和 / 64 × 100%
    • 用颜色标记各维度等级（绿/黄/红）
  3. 时间线表（Timeline Table）
    • 标注强制适用日期：2027年2月18日
    • 倒推各阶段里程碑节点
    • 计算剩余可用周数
  4. 各维度详评表（6个表）
    • 逐项填写：检查项描述、评级、现状描述、改进建议
    • 每项必须附具体证据或说明不足原因
    • 改进建议需可操作、有明确责任人和时限
  5. TOP5差距清单
    • 按影响度×紧急度矩阵排序
    • 标注「阻塞项」(Blocker) 或「可并行项」(Parallel)
    • 每项给出整改建议、预计工时、所需资源
  6. 整改路线图（Remediation Roadmap）
    • 甘特图式排程：按周为单位
    • 标注依赖关系（哪些必须先完成才能启动下一项）
    • 设置阶段检查点（Week 4 / Week 8 / Week 12）
  7. 分级附录（Grading Appendix）
    • A级 ≥80%：绿色通行，基础整改即可
    • B级 40-79%：黄色警示，需要系统性整改
    • C级 <40%：红色预警，需全面重建合规体系
填写原则：评估报告必须客观、有据。每项评级必须附具体证据或明确说明，不可凭主观印象打分。报告将作为客户合规审计的重要底稿。

📊 2.3 评分方法与客户沟通

评分计算公式

维度得分率 = 该维度实际得分 ÷ 该维度满分 × 100%
总体得分率 = 全部实际得分之和 ÷ 64 × 100%

示例：C维度（护照数据）满分18分
- C1=2, C2=2, C3=1, C4=0, C5=0, C6=1, C7=2, C8=1, C9=0
- C维度得分 = 2+2+1+0+0+1+2+1+0 = 9/18 = 50% → 黄色

客户沟通要点

场景沟通策略话术参考
得分≥80%（绿色） 肯定现有基础，聚焦少量差距 「贵司基础较好，主要需要补齐碳足迹数据和供应链溯源」
得分40-79%（黄色） 强调紧迫性，提供清晰路径 「还有几项关键差距需要系统整改，但16周时间充裕，我们有标准化流程」
得分<40%（红色） 管理恐慌，给出信心 「虽然差距较大，但只要现在开始，我们有成功案例可以复制。建议优先解决阻塞项」
沟通技巧：永远先说「我们已经确认做到的部分」，再说「还需要补充的部分」。避免使用「不合格」「不达标」等负面词汇，改用「待完善」「待补充」。

第三章 数据采集操作指南

📊 3.1 数据项标准清单使用

文件：03_DPP数据项标准清单_电池版.xlsx

清单概述

基于 (EU) 2023/1542 Annex XIII 要求，定义了 38个标准数据字段，分为以下类别：

类别字段数可见性说明
制造商信息5项公开企业名称、地址、、EORI号、DPP ID
产品标识4项公开电池型号、批次号、生产日期、序列号
化学成分6项受限物质名称、CAS号、重量占比、危险分类
原材料溯源5项受限关键原材料、矿区、国家、供应链路径
性能参数6项公开额定容量、标称电压、能量密度、循环寿命
可持续性指标5项公开碳足迹、回收材料含量、回收效率
合规认证4项公开CE证书编号、合格评定、检测报告编号
回收信息3项公开拆卸指引、回收方式、回收设施代码

可见性说明

  • 公开(Public)：任何扫码用户可查看（终端消费者、监管机构）
  • 受限(Restricted)：仅授权方可查看（监管机构、供应链合作伙伴，需权限验证）
数据敏感性：化学成分和供应链溯源数据属于商业机密，必须在DPP系统中正确设置访问权限，仅限Restricted可见性级别。泄露可能导致客户商业损失。

第四章 注册上线操作指南

🔐 4.1 eIDAS证书办理

参考文件：06_eIDAS与欧代办理指引.docx

什么是eIDAS证书？

eIDAS (Electronic Identification, Authentication and Trust Services) 证书是EU DPP Registry用于验证经济运营商身份的数字证书。相当于企业在欧盟数字世界的「身份证」。

办理流程

  1. 选择QTSP（Qualified Trust Service Provider）
    • QTSP必须是欧盟成员国认可的合格信托服务提供商
    • 推荐QTSP列表（截至2026年）：
      • Signicant（德国） — 审批较快，4-6周
      • Infocert（意大利） — 费用较低
      • Chambersign（德国工商大会） — 权威性高
      • Legaltrust（法国） — 法语区客户首选
    • 费用范围：€500-2,000/年（取决于证书类型和有效期）
  2. 准备申请材料
    • 企业注册证明（营业执照公证件 + 翻译件）
    • 法人身份证明（护照复印件）
    • VIES增值税号验证
    • EORI号（Economic Operators Registration and Identification）
    • 授权签字人委托书
  3. 提交申请
    • 通过QTSP在线平台提交
    • 部分QTSP要求视频验证身份
    • 支付证书费用
  4. 审核与签发
    • 审核周期：4-8周（建议提前启动）
    • 签发后获得：证书文件（.p12/.pfx）+ PIN码
    • 证书有效期：1-3年（建议选3年）
时间风险：eIDAS证书办理是最常见的延误环节。务必在Phase 2（差距分析）完成后立即启动，不要等到Phase 5。如一家QTSP延误，立即切换到备选QTSP。

备选方案

如eIDAS证书未能及时获得：

  • 备选QTSP列表准备至少3家
  • 可先使用测试证书在沙箱环境完成技术对接
  • 与EU Registry沟通临时接入方案

🏛️ 4.2 欧盟授权代表（EU Authorised Representative）

为什么需要欧代？

根据 (EU) 2023/1542 第40条，非欧盟设立的经济运营商必须指定一个在欧盟境内设立的授权代表，负责DPP合规相关事务。

选择标准

标准要求权重
所在国EU成员国，优先德国/荷兰/卢森堡（法规意识强）★★★★
行业经验有电池/电子行业合规经验★★★★★
语言能力英语流利，最好有中文服务团队★★★
费用€2,000-6,000/年（视服务范围）★★★
响应速度48小时内响应监管问询★★★★

授权协议要点

  • 授权范围：明确覆盖DPP合规的具体职责
  • 授权期限：与电池预期使用寿命匹配（至少10年）
  • 通信机制：监管机构联络方式、响应时效
  • 数据权限：欧代访问DPP数据的权限边界
  • 终止条款：提前终止的通知期和过渡安排
  • 费用结构：年度固定费 + 额外服务费
  • 责任划分：欧代仅承担代表责任，不承担制造商合规责任

第六章 常见问题处理（TOP 15 FAQ）

以下列出实施过程中最常遇到的15个问题及标准处理方案。点击问题展开详细解答。

Q1: 客户无法提供供应商数据怎么办？

问题场景：客户上游供应商（特别是中国原材料供应商）拒绝配合填写问卷或提供溯源数据。

处理方案：

  1. 第一步：使用 05_供应商数据问卷_中英双语.docx 正式发放，明确法规强制要求
  2. 第二步：两轮催办后仍不配合 → 请客户采购负责人介入施压
  3. 第三步：替代方案 — 使用行业公开数据库（如USGS矿产数据、ICSG铜业数据）补充
  4. 第四步：极端情况 — 委托第三方审计机构（如SGS/BV）进行现场审计获取数据
  5. 文档记录：在评估报告中标注该数据项为「第三方替代数据」，说明原因
Q2: 电池类型分类不明确怎么判断？

Q3: eIDAS证书办理延误怎么办？

常见延误原因：材料不完整、QTSP审核排队、视频验证安排困难。

处理方案：

  1. 提前准备至少3家QTSP备选名单
  2. 第一家提交后2周无进展 → 立即启动第二家
  3. 同步准备完整材料（避免来回补充）
  4. 使用测试证书在沙箱环境先行完成技术对接
  5. 正式证书到手后直接切换生产环境

预防：Phase 2完成后立即启动，不等到Phase 5。

Q4: 客户数据格式与Registry API不兼容？

常见不兼容情况：客户内部使用非标准字段命名、单位不一致、编码规则不同。

标准转换流程：

  1. 获取EU Registry API Schema文档
  2. 建立字段映射表：客户字段 → API标准字段
  3. 单位统一转换（参考数据手册中的单位规范）
  4. 编码标准化（DPP-ID格式：国家代码-企业代码-产品代码-校验位）
  5. 编写转换脚本或使用中间件

工具：建议使用Python脚本或Excel Power Query进行批量转换，避免手工操作出错。

Q5: 客户有多个工厂/多个产品线怎么办？

处理策略：

  • 按工厂分别评估 — 每个工厂独立填写核查清单
  • 按产品线分批上线 — 优先处理出口量最大的产品线
  • 统一数据标准 — 确保所有工厂使用同一套数据手册模板
  • 分别申请DPP-ID — 每个工厂+产品线组合需要独立DPP
  • 项目时间可能延长20-30%，需提前与客户沟通
Q6: 客户已有部分认证但即将过期？

处理方案：

  1. 在核查清单中评级为「部分达标」(1分)
  2. 评估报告中标注证书有效期和续期截止日
  3. 整改路线图纳入「证书续期」任务项
  4. 建议客户在到期前3个月启动续期流程
  5. 过渡期：如续期已在进行中，可提供续期申请受理回执作为临时证据
Q7: 客户是贸易商而非制造商，如何处理？

关键判断：根据电池法规，DPP义务主体是「制造商」(manufacturer)。如果客户仅为贸易商：

  • 贸易商作为「进口商」(importer)也有部分合规义务
  • 需要确认其是否以自己的品牌销售（白标/OEM情况）
  • 如以自己品牌销售 → 法规视其为制造商，需承担全部DPP义务
  • 如纯粹代理进口 → 需确保上游制造商已完成DPP注册
  • 建议：这种情况需重新评估服务范围，可能转向「DPP合规验证」而非「DPP注册」服务
Q8: 供应商问卷回收率太低（<50%）怎么办？

升级处理流程：

  1. 请客户高层直接联系供应商高层（对等施压）
  2. 提供简化版问卷（仅Part A + Part C + Part G，减少填写负担）
  3. 提供填写协助（电话指导/视频会议辅助填写）
  4. 设置硬性截止日期并说明后果
  5. 如仍无效：委托第三方进行供应链审计
  6. 在数据手册中标注「供应商数据缺失 — 使用替代数据源」
Q9: 碳足迹数据客户完全没有怎么办？

碳足迹是DPP中复杂度最高的数据项之一。处理方案：

  1. 推荐合作碳核算机构（如SGS、TÜV、BV）进行产品碳足迹核算
  2. 核算周期通常4-8周，费用约¥30,000-80,000/产品
  3. 过渡方案：使用行业平均值+客户实际能耗数据进行估算
  4. 在整改路线图中标注为高优先级项
  5. 如时间紧迫，建议先使用估算值上线，后续替换为精确值
Q10: 客户电池出口量很小，是否有必要做DPP？

必须做。法规无最小出口量豁免。只要在EU市场销售，无论量大小，都必须有DPP。

沟通要点：

  • 2027年2月18日后无DPP的电池不允许在EU市场销售
  • 海关可能查验，无DPP将被扣留
  • 早准备 = 先发优势，竞争对手可能还在观望
  • 量小的客户流程更简单（SKU少、供应链短），成本反而更低
Q11: 客户已经有ERP系统，如何对接DPP？

对接方案：

  1. 评估现有ERP的数据字段覆盖度（与38项DPP数据对比）
  2. 识别Gap：哪些数据ERP中有、哪些需要新建字段
  3. 推荐两种模式：
    • API直连模式（推荐）：ERP数据通过API自动同步到DPP平台
    • 数据导出模式：定期从ERP导出数据，手工/半自动导入DPP
  4. 无论哪种模式，都需要数据映射和格式转换
  5. 建议客户IT部门参与Phase 3-5的技术对接工作
Q12: 客户需要同时满足多国法规（如EU+美国+韩国）？

处理策略：

  • DPP数据手册设计时预留扩展字段（其他市场要求的数据项）
  • 核心数据（化学成分、性能参数）各国要求高度重叠，可复用
  • 差异项单独管理（如美国可能要求UL认证、韩国要求KC认证）
  • 建议客户建立统一的产品合规数据中台
  • 服务范围需扩展，项目报价相应调整
Q13: 评估发现客户得分极低（<40%），客户信心受挫？

沟通策略：

  1. 先肯定已做到的部分（哪怕只有20%也是基础）
  2. 强调时间节点仍有缓冲（距2027.2还有充足时间）
  3. 展示成功案例和标准化流程，给客户信心
  4. 将大目标拆解为小步骤，每周可交付可见进展
  5. 提供分阶段方案：先确保2027.2前核心产品上线，其余后续补齐
  6. 调整团队配置：低分客户需配备更有经验的顾问
Q14: 注册提交后EU Registry审核退回怎么办？

常见退回原因及处理：

退回原因处理方案
必填字段缺失补充缺失数据后重新提交
数据格式错误按API Schema修正格式
eIDAS证书验证失败检查证书有效期和配置
产品信息不完整补充缺失的产品技术数据

流程：收到退回通知 → 分析原因 → 修正数据 → 内部复核 → 重新提交（通常2-3个工作日内完成）

Q15: 项目周期被客户压缩到8周以内怎么办？

快速通道方案（适用于基础较好、得分≥60%的客户）：

  1. Week 1：启动评估 + 差距分析合并（3天评估 + 2天分析）
  2. Week 2-4：数据采集 + 整改并行（全员投入）
  3. Week 3：同步启动eIDAS（加急通道，部分QTSP支持2周加急）
  4. Week 5-6：系统对接 + 沙箱测试
  5. Week 7-8：正式提交 + 上线验证
风险提示：快速通道成功率约60-70%。必须在项目启动时与客户明确：加速=风险增加，尤其是eIDAS办理和碳足迹核算环节可能成为瓶颈。建议保留延期4周的缓冲条款。
