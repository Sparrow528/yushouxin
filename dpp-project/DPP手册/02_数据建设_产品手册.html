Part 01

您面对的问题

差距评估已经完成，您知道了"差什么"——但知道问题不等于解决问题。从「知道缺什么」到「数据齐备可提交」，中间还有大量系统性工作要做。

📋

知道差距≠填补差距

差距评估报告清楚地告诉您71个数据点缺了哪些，但每个缺口都需要实际收集、整理、核验——这是一项系统性工程，不是看看报告就能自动完成的。

🏢

数据分散在多个部门

基本信息在行政/关务，技术参数在研发，检测报告在质量，BMS数据在IT，采购数据在供应链——没有一个部门掌握全貌，跨部门协调往往推不动。

🤝

供应商不配合

再生含量、CRM原产国、冶炼厂信息等关键数据握在上游供应商手中。问卷发出去石沉大海、回复质量差、数据口径不一致——企业自己催收缺乏专业工具和谈判经验。

📊

数据格式不统一

不同供应商给的数据格式各异——Excel、PDF、邮件甚至口头回复，单位不一、口径不同，没有标准化模板，汇总后无法直接使用，还需大量人工清洗转换。

🔍

缺乏核验标准

收到的数据是否准确、是否完整、是否符合法规口径？没有系统的核验流程，错误数据一旦提交到注册中心，后果比数据缺失更严重——可能触发市场监督调查。

⏰

时间紧迫

2027年2月18日起，EV/LMT/工业电池(>2kWh)必须有电池护照方可投放欧盟市场。数据采集、供应商协调、核验整理，每一项都需要时间，越晚启动成本越高。

数据收集的5大难点详解

难点具体表现影响
1. 数据分散研发部门掌握技术参数、采购部门掌握供应商信息、质量部门掌握检测报告、IT部门掌握BMS数据——各部门各自为政，数据孤岛严重跨部门协调耗时2-4周，且容易遗漏关键数据
2. 供应商不配合缺乏强制力要求供应商提供数据；沟通成本高，中小供应商不理解DPP要求；数据质量参差不齐，回复内容不完整供应商数据回收率通常不足50%，严重拖延进度
3. 格式不统一Excel/PDF/邮件/口头回复混杂；单位不一致（如容量用Ah vs Wh）；数据口径不统一（如再生含量的计算基准不同）数据清洗工作量巨大，且容易出错
4. 动态数据难追踪SoH（健康状态）、循环次数、温度历史等使用数据持续变化；需要与BMS系统对接或定期人工采集静态数据一次收集即可，但动态数据需要建立持续更新机制
5. 法规合规判断难71个数据点中哪些必须填、哪些可选、哪些条件适用——不同电池类别（EV/LMT/工业）要求不同；部分数据点截至2027年2月暂不需要填写判断错误可能导致提交后被退回或触发合规风险
⚡

核心矛盾：差距评估解决了"不知道"的问题，但解决"怎么补"需要专业的数据规划能力、供应商管理经验和标准化核验体系。数据建设服务，就是帮您把差距变成可执行、可交付的完整数据底册。

Part 02

我们能帮您做什么

基于差距评估的结果，帮您建立每个电池型号的完整数据底册，辅导您从供应商那里回收缺失数据，最终形成可以直接提交注册中心的数据手册。

一句话总结：不用自己摸索数据怎么收、问卷怎么发、供应商怎么催——我们全包。

我们的方法论：四步数据建设体系

我们将复杂的数据建设工作拆解为四个标准化步骤，确保每个环节可控、可追溯、可复核：

1

标准化数据卡

为每个电池型号（SKU）创建一张数据卡，包含35个标准字段，覆盖法规全部数据要求。字段分6组管理，每个字段标注状态：✅已填 / ⏳待补 / ⚪不适用。

2

结构化采集

基于数据卡的缺口分析，制定供应商问卷（中英双语7个Part）+ 催收机制（7-14-21天三级节奏）+ 责任分工（客户内部谁负责什么、我方负责什么）。

3

三级数据质量检查

L1 逻辑校验：数值范围合理性、单位一致性、必填项完整性
L2 交叉验证：多来源数据比对、历史趋势分析、行业基准对比
L3 法规合规：71数据点逐项检查、强制项确认、条件适用项判断

4

数据手册整合

将所有通过核验的数据整合为完整数据手册——包含数据卡、采集台账、供应商清单、合规性报告——可直接提交注册中心用于护照数据申报。

数据卡35字段详解（分6组）

每个电池型号一张数据卡，35个字段分6组管理，严格对应欧盟电池法规 (EU) 2023/1542 附录XIII的数据要求：

分组字段数包含字段数据来源
基本信息组 9项 制造商名称、地址与联系方式、电池类别、电池型号、序列号/批号、制造日期、制造地点、化学体系、电池重量 企业内部 / 生产系统 / 规格书
技术参数组 6项 标称电压、额定容量、额定功率/能量、循环寿命（预期循环次数）、预期寿命（日历年限）、质保条款 规格书 / 研发部门 / 测试报告
材料组 6项 有害物质信息、电池组件清单、关键原材料(CRM)清单、CRM原产国、冶炼厂/精炼厂名称与地址、再生含量比例（钴/铅/锂/镍） 供应商 / BOM表 / 检测报告
合规组 5项 CE认证/DoC符合性声明、测试报告、碳足迹声明、碳足迹等级、供应链尽职调查政策 认证机构 / LCA机构 / 合规部门
供应链组 4项 供应商名称、供应层级（一级/二级）、负责的数据字段、数据提供日期与版本 采购部门 / 供应商问卷
动态数据组 5项 健康状态(SoH)数据来源与更新频率、充放电循环次数、温度历史记录、故障与维护记录机制、电池状态（原始/再利用/废弃物） BMS系统 / IT部门 / 售后部门
📌 字段完整性说明

35个字段并非所有型号都必须全部填写。每个字段根据电池类别（EV/LMT/工业）和企业实际情况标注适用性。不适用的字段标注"⚪不适用"并注明法规依据。所有"✅已填"字段必须挂载证据文件编号，可追溯到原始文件。

服务包含两个模块

📐

模块一：数据规划

为每个电池型号建立标准化的DPP数据卡，明确数据缺口与采集路径

  • 数据卡建立流程：从差距评估报告迁移已有数据 → 为每个型号创建数据卡模板 → 字段状态标注（✅已填/⏳待补/⚪不适用）→ 数据缺口自动统计
  • 缺口分析报告：总体缺口统计（多少字段待补）→ 按来源分类（内部数据/供应商数据/第三方检测）→ 按优先级分类（阻塞项/重要项/可选项）
  • 采集计划：供应商清单（名称、联系人、负责的数据字段）→ 采集时间表（每批次问卷发放/回收/核验时间）→ 责任分工
  • 准备供应商问卷：中英双语标准问卷（Part A-G，7个部分）
🔗

模块二：供应商采集辅导

代发问卷、催收管理、三级核验——确保供应商数据高质量入库

  • 问卷发放流程：中英双语标准问卷（Part A-G共7部分）附采集指引信（用途说明+保密承诺+截止日期）
  • 催收管理机制：第1周发放+说明电话 → 第2周未回复供应商提醒 → 第3周逾期供应商升级（客户协助）→ 第4周最终催收+替代方案讨论
  • 数据核验三级体系：L1 逻辑校验（数值范围/单位/必填项）→ L2 交叉验证（多源比对/趋势分析/基准对比）→ L3 法规合规（71数据点逐项检查）
  • 数据录入：核验通过的数据录入数据手册，形成完整底册
📌 两个模块的关系

数据规划是框架，供应商采集是填充。先做数据规划建立数据卡和缺口分析，缺口中"供应商数据缺口"直接进入采集辅导的工作范围。两个模块打包执行效果最佳，避免信息断层和重复沟通。

Part 07

常见问题

以下是客户最常问到的10个问题。如还有其他疑问，欢迎直接联系项目经理。

Q1：数据建设和差距评估有什么区别？

差距评估是"诊断"——告诉您71个数据点哪些合格、哪些有缺口、缺口有多严重，产出的是评估报告。数据建设是"治疗"——基于诊断结果，实际帮您建数据卡、发问卷、催供应商、做核验，最终产出可直接提交注册中心的数据手册。

简单说：评估告诉您"差什么"（产出报告），建设帮您"补上来"（产出数据手册）。两项服务是上下游关系，建议连续执行。

Q2：我的供应商不配合怎么办？

这正是我们服务的核心价值之一。我们有成熟的四阶段催收体系：

  • 第1周：首次发放前先电话沟通说明重要性，再发正式问卷
  • 第2周：未回复供应商温和提醒，提供填写协助
  • 第3周：升级催收，同步通知您公司采购部门介入
  • 第4周：最终催收 + 替代方案讨论（如第三方检测）

配合度评估报告会标注A/B/C三级，对C级供应商给出更换或升级沟通的具体建议。多年经验告诉我们，专业第三方出面催收的回复率远高于企业自行催收。

Q3：需要我提供什么资料？

主要需要5类资料，我们会通过结构化采集表引导您提供，不需要您提前整理齐全：

  • ① 差距评估报告（如由我方完成可直接交接）
  • ② 电池型号清单（SKU列表，含型号名称、电池类别、规格书）
  • ③ 内部已有数据（制造商信息、技术参数、认证文件、BOM表、测试报告等）
  • ④ 供应商名单及联系方式（名称、联系人、邮箱、电话、供应材料）
  • ⑤ 指定一名内部对接人（协调研发、质量、采购、IT各部门的数据提供）
Q4：数据建设周期多长？

标准版4-6周，旗舰版6-8周。实际周期取决于两个关键因素：

  • SKU数量：型号越多，数据卡建立和核验工作量越大
  • 供应商配合度：这是最长路径项——供应商配合度高可更快完成，普遍不配合则需延长催收周期

签约前我们会如实评估并在项目计划中写明预期周期。加急项目可压缩约30%时间，需加收30%加急费用。

Q5：如果某些数据确实收不到怎么办？

首先分析原因，分两种情况处理：

  • 供应商不愿提供：通过升级催收、采购部门施压解决。如仍不配合，评估替代方案（委托第三方检测机构出具报告）
  • 供应商自己也没有：协助协调第三方检测（如碳足迹LCA检测、再生含量检测），我们可推荐合作检测机构

如果穷尽所有手段仍无法获取，在数据手册中如实标注"缺口"并附补救方案与时间表，同时评估是否影响护照注册。我们的目标是最大化数据齐备率，但不会对无法获取的数据做虚假处理。

Q6：数据手册做好后，可以直接用于注册吗？

可以。数据手册是按照注册中心的数据格式要求编制的：

  • 所有字段与法规71个数据点一一对应
  • 经三级核验（L1逻辑校验+L2交叉验证+L3法规合规）确认数据质量
  • 格式满足DPP注册中心的提交要求

数据手册交付后可直接进入③注册上线服务，完成护照数据的系统提交。如果您选择自行注册，数据手册同样可直接使用。

Q7：后续数据更新怎么办？

欧盟电池法规要求动态数据持续更新，这是长期合规的关键：

  • 动态数据：SoH（健康状态）、循环次数等需持续更新（频率取决于电池类别和使用场景）
  • 年度数据：再生含量比例等需每年刷新
  • 法规变化：法规修订可能导致新增数据要求

数据手册交付时会附带《数据维护计划》，说明更新频率和责任人。您也可以选择签订④年度数据维护合同，由我们持续跟踪数据更新和法规变化，确保护照数据始终合规。

Q8：你们的数据模板是标准的吗？

是的，完全基于法规标准设计：

  • 数据卡的35个字段严格对应欧盟电池法规 (EU) 2023/1542 附录XIII的71个数据点要求
  • 字段定义与欧委会数据点指南（2026年8月v2.0版）一一对应
  • 供应商问卷的7个Part（A-G）覆盖了所有需要供应商提供的数据项
  • 模板基于法规原文和行业最佳实践设计，不是自创标准

守信财税深耕财税合规领域18年，是专注于为中国企业提供欧盟合规服务的专业机构。我们的DPP业务线依托对(EU) 2023/1542电池法规的系统性研究，结合电池行业的供应链实际，为电池企业提供从①差距评估 → ②数据建设 → ③注册上线 → ④年度托管的一站式合规服务。标准化流程、工具化交付、全链条衔接——帮助中国电池企业高效、合规地进入欧盟市场。
