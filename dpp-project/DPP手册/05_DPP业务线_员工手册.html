Part 1

第一部分：我们是谁

了解公司的背景和DPP业务线的定位，是每位新员工的必修课。

公司背景

18年财税实战经验，深耕企业服务领域。咨询创始人，服务数千家企业客户，建立了深厚的财税专业能力和企业信任。

业务线定位

DPP业务线

专注帮助中国电池企业完成欧盟电池法规 (EU) 2023/1542 的合规要求——从差距评估到数据建设到护照上线到持续维护，提供全链条一站式服务。

我们的使命：让每一家中国电池企业，都能轻松合规地进入欧盟市场。

市场机遇

⏰

强制时间窗口

2027年2月18日起，电动汽车电池、轻型交通工具电池（E-bike等）、容量＞2kWh的工业电池，必须在欧盟注册中心持有有效的电池护照才能在欧盟市场销售。

🏭

中国是全球最大电池生产国

全球超过70%的锂电池产能在中国。欧盟电池法规直接影响数千家中国电池制造企业，合规需求巨大而紧迫。

🎯

我们的核心优势

法规专业 + 电池行业理解 + 全链条服务。不是纯技术咨询公司，也不是纯代理机构——我们是唯一能从评估到上线到持续维护全包的服务商。

💡 给新员工的提醒

面试时客户最常问的问题：「你们做DPP多久了？有什么资质？」——我们的答案是：18年财税合规经验 + 完整的四阶段服务体系 + 已服务多家电池企业的实战案例。请用自信的语气传达这些信息。

Part 5

第五部分：协作规则

规范的协作流程是高质量交付的保障。以下是每个项目必须遵循的协作规则。

项目启动流程

1

签约

商务拓展完成合同签约，收取首付款。项目经理收到签约通知后启动项目准备。

2

启动会

项目经理组织内部启动会 + 客户启动会。明确项目范围、团队分工、沟通机制、交付时间表。

3

范围确认

与客户确认服务范围、电池类型、SKU数量、特殊需求。签署范围确认书。

4

项目计划

项目经理制定详细项目计划（甘特图），分配任务给团队成员，设定里程碑节点。

5

执行交付

按计划执行，定期向客户汇报进度。完成后进行内部质量审核 → 客户验收 → 收尾。

沟通机制

沟通形式 频率 参与人 内容
周例会 每周一 全项目组 上周进展、本周计划、风险预警
日报 每日 各岗位 → 项目经理 今日完成、明日计划、阻塞问题
客户汇报 每周/双周 项目经理 → 客户 进度报告、待确认事项、风险提示
即时沟通 随时 按需 紧急问题、快速确认（企微/飞书群）

文件管理规范

📁

标准工具箱

每个服务配套标准文件集：差距评估20个、数据建设16个。所有文件必须从工具箱取用，不得自行创建替代版本。

📝

文件命名规范

格式：[客户名]_[服务类型]_[文件名称]_v[版本号]
示例：宁德时代_差距评估_报告_v1.2

🔄

版本控制

每次修改必须更新版本号（v1→v2→v3...）。重要修改在文件内标注修改记录。客户确认版本标注为「终稿」。

质量控制

✅ 双人审核制度

所有交付物必须经过「制作人自检 → 第二人复核」双人审核流程。法规专家出具的文件需由另一位法规专家或业务负责人复核。客户验收前必须完成内部审核。

验收标准

每份交付物都有明确的验收清单。项目经理对照清单逐项检查，全部通过后才可提交客户。

客户确认

关键里程碑节点需要客户书面确认（邮件/签字）。范围变更需签署变更确认书。

保密要求

🔒 保密红线
  • NDA：所有项目启动前必须签署保密协议
  • 数据安全：客户数据仅限项目组成员访问，禁止通过个人邮箱/网盘传输
  • 客户信息保护：客户、商业信息、技术资料等一律不得外泄
  • 离职交接：离职前必须完成所有客户资料的交接和清理

Q1：新员工如何快速上手？

第一周：通读本手册 + 浏览法规数据库 + 阅读知识库案例 → 建立整体认知
第二周：跟随mentor参与实际项目，观察学习 → 了解实际工作流程
第三周起：在mentor指导下承担具体任务 → 逐步独立负责模块
关键动作：有问题随时问，不要自己闷头研究。团队每周一例会也是学习的好机会。

Q2：客户问技术问题怎么办？

原则：在自己职责范围内的，直接回答；超出范围的，不要猜测，先记录下来，转给对应专家。

  • 法规问题 → 转法规专家
  • 数据问题 → 转数据分析师
  • 技术对接问题 → 转技术支持
  • 不确定的 → 先回复客户「我帮您确认后回复」，24小时内给出答案

绝对禁止：不懂装懂、给出错误的法规解读或技术承诺。

Q3：项目延期怎么办？

第一步：立即通知项目经理，说明延期原因和预计影响范围。

第二步：项目经理评估后，与客户沟通调整时间表（如需要）。

第三步：内部复盘，找出延期根因，制定预防措施。

关键：越早报告越好。隐瞒不报导致最后时刻才爆雷是最大的忌讳。

Q4：客户投诉怎么处理？

原则：先倾听、再道歉、后解决。

  • 倾听：让客户完整表达不满，不要打断或辩解
  • 道歉：为客户的不良体验道歉（不代表承认错误）
  • 记录：详细记录投诉内容和客户诉求
  • 上报：立即上报项目经理和业务负责人
  • 解决：24小时内给出解决方案，48小时内落实
  • 复盘：纳入案例库，避免同类问题再次发生
Q5：如何申请使用标准工具箱？

方式：标准工具箱存放在公司共享文件服务器的「DPP工具箱」目录中。新员工入职时由IT开通访问权限。

使用规则：

  • 只使用最新版本的文件模板
  • 不得修改模板中的固定内容（如法规条款引用）
  • 客户定制内容填写在模板指定区域
  • 如发现模板有问题，向项目经理反馈，由法规专家统一更新
