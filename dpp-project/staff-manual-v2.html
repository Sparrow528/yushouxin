业务背景（新员工必读）

1.1 我们做什么

  • 帮助中国电池企业完成欧盟电池法规 (EU) 2023/1542 的合规要求
  • 核心是电池护照（Art.77），2027年2月18日强制实施

服务体系全景（核心章节）

2.1 7阶段服务路径 🆕 产品经理版本

完整的7阶段→4服务映射，理解每个阶段做什么、对应哪个服务产品：

7阶段 对应服务 说明
01 适用与责任 ① 差距评估 判断产品范围、责任主体、适用时间
02 数据任务设计 ② 数据建设 把71个数据点变成可执行任务
03 采集与治理 ② 数据建设 形成可追溯数据包
04 护照创建 ③ 注册上线 标识、权限与展示配置
05 托管与备份 ③ 注册上线 建立持续访问能力
06 身份与登记 ③ 注册上线 确认主体并完成登记
07 持续运行 ④ 年度托管 变更、同步与审计
关键理解：7个阶段是合规的客观时序，4个服务是我们的产品化交付。阶段02-03合并为数据建设，阶段04-06合并为注册上线。

关键专业知识（员工必须掌握）

3.1 数据任务6问法 🆕 新增

每个数据字段必须回答以下6个问题，这是我们做数据任务设计的核心方法论：

1
要不要做？
必填 / 条件适用 / 可选 / 暂不适用
2
对应哪件产品？
企业级 / 型号级 / 批次级 / 单体级
3
由谁提供？
研发 / 采购 / 质量 / IT / 售后 / 供应商
4
凭什么证明？
BOM / 报告 / 声明 / 系统记录 / 供应商证据
5
谁可以看？
公众 / 监管 / 合法利益 / 内部支持
6
何时要更新？
换料 / 换厂 / 报告失效 / 生命周期变化
6问法不是走过场——每个数据点都要逐条落实。缺少任何一问的答案，该项目数据任务就不算完成。

3.2 三层访问权限 🆕 新增

扫码展示的核心逻辑——不同角色看到不同信息：

🌐 公众访问

无需证明身份 → 公开产品信息 + 符合性 + 废弃处理

🏛️ 监管/符合性访问

公告机构 / 市监机构 / 欧委会 → 测试报告 + 受限资料

🔧 合法利益访问

维修 / 再制造 / 梯次利用 / 回收 → 详细组成 + 拆解 + 安全 + 单体动态数据

2026年Q4：访问权实施法将出台，进一步确定合法利益主体名单。请密切关注，届时可能需要更新客户数据权限配置。

3.3 四道交付控制门 🆕 新增

不是等到上线前才统一检查，每完成一段工作就过控制门：

01 范围控制

产品类别 + 适用日期 + 责任角色已确认

02 数据质量控制

每项数据有来源 + 责任人 + 证据 + 版本

03 发布与登记控制

标识 + 权限 + 数据源 + 登记主体一致性已核对

04 运行与退出控制

变更触发 + 备份 + 恢复 + 迁移已落实

员工须知：不会等到上线前才统一检查，每完成一段工作就过控制门。控制门不过，不进入下一阶段。

3.4 碳足迹专项说明 🆕 新增

  • 首批DPP（2027.2.18）暂不统一填报碳足迹声明与标签
  • 第7条碳足迹义务另有分类别时间线
  • 现阶段保留底层数据即可（型号/工厂/BOM/能源/供应商）

客户问"要不要做碳足迹" → 答：先把数据主线做好，按产品类别和正式规则再决定是否启动核算。

3.5 四项关键风险 🆕 新增

风险1：产品分类与责任错位

小容量LMT不自动排除——需要逐项判断适用范围和责任主体，不能凭直觉分类。

风险2：证据与产品版本脱节

报告是否覆盖拟投放型号/工厂/物料版本？证据过时或范围不匹配是常见问题。

风险3：供数不足或披露过度

为必需信息建立供数机制，按规则区分访问权限。既不能缺数据，也不能把该限制的信息暴露给公众。

风险4：完成上线却缺少持续管理

二维码可扫 ≠ 合规完成。上线后数据变更、法规更新、被查验都需要持续管理能力。

销售话术与FAQ

4.1 客户最常问的5个问题

Q1：你们做DPP多久了？有什么资质？ ▼

参考回答：18年财税合规经验 + 完整四阶段服务体系 + 标准化工具箱。我们不是只给建议的咨询公司，而是从头到尾帮您把护照做出来、上上去、管起来的全流程服务方。

Q2：我们产品要不要做DPP？ ▼

参考回答：EV电池、LMT电池、>2kWh工业电池需要，普通便携式电池暂不强制。我们先帮您判断适用范围——这就是差距评估第一步做的事。

Q3：定价怎么算？ ▼

参考回答：按电池类型、SKU数量和服务档位。差距评估¥8万起，全套首年¥66万起。具体报价在差距评估完成后可以精确给出。

Q4：碳足迹要不要一起做？ ▼

参考回答：首批护照暂不统一填报碳足迹，先把数据主线做好，按正式规则再决定。现阶段保留底层数据即可。

Q5：上线之后呢？还要继续花钱？ ▼

参考回答：是的，法规持续变化、数据需要更新、可能被查验。年度托管确保持续合规，这是法规要求，不是可选项。就像年报审计一样——不是做一次就永远不用做了。

4.2 销售红线 🆕 新增

以下内容绝对不能对客户说：

❌ 销售红线——触碰即违规

  • "做了CE就不用做DPP了"
    → CE解决产品合规，DPP让信息持续可查，互不替代
  • "碳足迹现在就要做"
    → 首批暂不统一填报，不能误导客户提前投入
  • "上线就完事了"
    → 上线后需要持续维护，否则合规状态会失效
  • 给出具体的法规解读
    → 转法规专家。销售人员不做法规解读，这是专业边界
红线不是建议，是底线。违反红线不仅影响客户信任，更可能造成合规事故。

数据任务设计 / 采集辅导 / 治理校验

项目协调 / 客户沟通 / 交付验收
⚙️
技术支持
平台接入 / 护照配置 / 托管备份

5.2 协作规则

项目启动流程
  • 客户签约 → 项目经理立项 → 分配法规专家+数据顾问
  • 差距评估启动 → 法规专家主导 → 2周内交付评估报告
  • 评估通过 → 数据顾问介入 → 数据建设启动
  • 数据达标 → 技术支持介入 → 注册上线
  • 上线完成 → 转年度托管 → 项目经理持续协调
文件命名规范

[客户名]_[服务类型]_[文件名称]_v[版本号]

例：宁德时代_差距评估_适用范围判断_v1.0

双人审核

法规专家出具的文件需由另一位法规专家或项目经理复核签字，单人出具不生效。

工具箱文件必须从标准模板取用

不得自行创建。标准模板库由法规专家维护，如有新增需求先提模板变更申请。
