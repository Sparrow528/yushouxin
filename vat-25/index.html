北京某制造企业，厂房出险获保险赔付200万，维修费150万（进项19.5万）——进项转不转？

旧做法（各地口径不一）

保险赔付不征增值税 → 对应的维修进项一律转出

−19.5万

企业白白多交了19.5万税款 💸

新规则（25号公告）

保险赔付属于白名单 → 进项正常抵扣，无需转出

+19.5万

企业直接省下19.5万 ✅

WHITE LIST

✅ 白名单：6类非应税交易，进项可正常抵扣

以下6类不征增值税的交易，企业为取得这些收入或发生这些行为而采购所产生的进项税额，可以正常抵扣，无需做进项转出。

1 保险赔付
北京某精密机械加工厂，厂房和精密设备投保了财产险，年保费12万。2026年因电路故障发生火灾，厂房维修费150万、设备修复费80万，保险公司理赔200万。
可抵扣进项税额
26.5万
维修+修复进项 = (150+80) ÷ 1.13 × 13% ≈ 26.5万
保险赔付虽不征增值税，但维修费对应的26.5万进项税额正常抵扣，无需转出。
踩坑提醒：很多老会计看到"保险赔付不征税"就习惯性全额进项转出，新规后千万别这么做了。
2 接受捐赠
北京某科技公司收到一家公益基金会捐赠的研发设备5台，公允价值60万元。公司为这批设备做了安装调试，发生安装服务费3万（进项0.39万），运输费0.5万（进项0.045万）。
可抵扣进项税额
0.435万
安装调试 0.39万 + 运输 0.045万 = 0.435万
接受捐赠本身不属于应税交易，但受赠方为接收捐赠发生的采购进项0.435万可以正常抵扣。
踩坑提醒：接受捐赠的进项转出是老问题，新规明确不用转出。
3 合同违约金
河北某建材贸易商与下游客户签订500万元钢材购销合同。签约后因客户原因合同取消，未发生任何货物交易。按合同约定，建材商收取违约金15万元。同期该建材商有办公租赁费进项1.2万、差旅费进项0.3万。
可抵扣进项税额
1.5万
办公租赁 1.2万 + 差旅 0.3万 = 1.5万
合同未履行且未发生应税交易，违约金15万不征增值税，相关进项1.5万正常抵扣。
关键区分：如果合同已履行、只是延迟付款的违约金 → 属于价外费用，要缴增值税。只有"合同未履行 + 未发生应税交易"双条件同时满足才适用白名单。
4 无偿提供服务
某集团公司总部为子公司免费提供管理咨询服务（非金融），总部发生咨询团队差旅费8万（进项1.04万）、外聘专家费5万（进项0.28万）。
可抵扣进项税额
1.32万
差旅 1.04万 + 外聘专家 0.28万 = 1.32万
无偿提供服务（不含金融商品转让）属于白名单，总部发生的1.32万进项正常抵扣。
例外提醒：如果是无偿转让金融商品（如无偿转让股权/债券），则不适用白名单，进项不得抵扣。
5 应收账款债权转让
北京某软件公司完成一个300万的软件开发项目（已开票缴税），形成应收账款300万。因资金周转需要，将应收账款以285万元转让给某商业保理公司。
转让行为不产生增值税；催收相关可抵扣进项
0.11万
催收该应收款发生律师费2万 → 进项 2÷1.06×6% ≈ 0.11万
转让自身应税交易产生的应收账款债权，不征增值税，相关进项可抵扣。
注意区分：转让"有价证券"（如股票、债券）不适用白名单，属于增值税应税行为。
6 不挂钩财政补贴
北京市某区向辖区内高新技术企业发放"创新发展引导基金"200万元，该补贴不与企业的销售收入或销售数量直接挂钩，而是用于支持企业研发能力建设。企业当年有研发设备采购进项18万。
可抵扣进项税额
18万
研发设备采购进项 = 18万
不挂钩的财政补贴不征增值税，企业采购进项18万正常抵扣。
判断标准：补贴与销售收入/数量不直接挂钩 → 白名单，可抵扣；直接挂钩 → 应税收入，需缴增值税。
BLACK LIST

❌ 黑名单：4类非应税交易，进项不得抵扣

以下4类交易不属于增值税应税范围，企业为此发生的进项税额不得从销项税额中抵扣，已抵扣的必须做进项转出。

1 非境内应税交易
北京某咨询公司受境外客户委托，为其提供完全在境外发生的市场调研服务，收取服务费50万。为完成该项目发生差旅费6万（进项0.78万）、翻译费2万（进项0.11万）。
不得抵扣进项税额
0.89万
差旅 0.78万 + 翻译 0.11万 = 0.89万，必须转出
交易不属于境内应税交易，进项0.89万不得抵扣，必须转出。
2 有偿转让股权
北京某民营企业老板将其持有的某有限责任公司30%股权以800万元转让给新投资方。为完成股权转让，支付了审计费15万（进项0.85万）、评估费10万（进项0.57万）、律师费20万（进项1.13万）。
不得抵扣进项税额
2.55万
审计 0.85万 + 评估 0.57万 + 律师 1.13万 = 2.55万，全部转出
转让非上市公司股权属于黑名单，审计+评估+律师费进项2.55万不得抵扣！
高频踩坑：这是最常见的错误。很多企业的审计费、评估费、律师费进项都违规抵扣了，接下来税务稽查必查这个。
3 股息红利
某投资公司持有A公司40%股权，2026年收到股息红利分红500万元。为持有和管理该股权投资发生基金管理费3万（进项0.17万）、托管费1万（进项0.06万）。
不得抵扣进项税额
0.23万
基金管理费 0.17万 + 托管费 0.06万 = 0.23万
持有股权取得的股息红利属于黑名单，对应进项0.23万不得抵扣。
注意：上市公司普通股分红同样在黑名单内，无论持有哪种形式的股权分红，对应进项均不得抵扣。
4 货物期货交易
某期货公司在上海期货交易所进行铜期货交易，2026年8月开仓买入100手铜期货合约，9月平仓获利50万（非实物交割）。交易过程中支付交易所手续费2万（进项0.11万）、信息费0.5万（进项0.03万）。
不得抵扣进项税额
0.14万
手续费 0.11万 + 信息费 0.03万 = 0.14万
货物期货交易非实物交割环节属于黑名单，进项0.14万不得抵扣。
关键界限：只有实物交割环节才属于增值税应税范围。期货平仓差价不征增值税，对应进项需转出。
KEY CHANGES

📋 其他关键变化

除白名单/黑名单外，25号公告还有几项直接影响日常开票和税务处理的配套规则变化。

场景 A
折扣开票新规 —— 备注栏折扣无效

案例：某电器经销商开展促销活动，商品原价10万（不含税），给予客户10%折扣即9万。

✅ 正确做法
在同一张发票"金额"栏分别注明原价10万和折扣1万 → 按9万计缴增值税
❌ 错误做法
只在备注栏写折扣信息 → 按10万全额计缴增值税，多交0.13万税

变化要点：明确"不含税价款"为销售额计算基准；备注栏折扣无效。

场景 B
电信服务赠品 —— 全部价款拆分核算

案例：某运营商推出套餐，月费199元（电信服务），赠送手机一部（市场价800元）。

✅ 新规处理
全部价款分开核算：电信服务199元按9%计税，手机按13%计税
❌ 旧规做法
手机作为"价外费用"并入电信服务统一按9%计税

变化要点：删除了"价外费用"表述，直接按全部价款拆分核算，各适用各自税率。

场景 C
放弃增值税优惠 —— 灵活选择起始时点

案例：某养老机构此前享受免征增值税优惠，因业务调整决定放弃优惠。

旧规则
提交备案后次月起才停止享受优惠
✅ 新规则
可自行选择放弃优惠的起始时点（当月即可），灵活性大幅提升

变化要点：不再受"次月生效"的限制，企业可根据实际业务需要自行选择放弃优惠的起始月份。

⏰ 过渡期提示

  • 2026年9月1日起正式执行，所有纳税人按新规处理增值税进项抵扣
  • 2026年1月1日至8月31日已发生但尚未处理的事项，可按25号公告追溯执行
  • 上半年做错的企业有更正窗口——白名单做了进项转出的可以更正回来，黑名单没转出的赶紧转出
