1
制造企业厂房出险获保险理赔，维修费进项处理
制造业 · 白名单第1项 · 保险赔付
✅ 进项可抵 ▾
场景描述
某制造企业因暴雨导致厂房受损，保险公司赔付维修费120万元。企业用赔付款采购建材（专票税额8.4万）、支付修理服务（专票税额1.2万），合计进项9.6万元。
判定逻辑
企业作为被保险人收到保险赔付 → 属于白名单第1项 → 不属于不得抵扣非应税交易 → 维修相关采购进项正常抵扣。
税额计算
采购建材进项：8.4万 修理服务进项：1.2万 合计可抵扣进项：9.6万 ✓ 实际维修成本：120 - 9.6 = 110.4万
💡 过去部分地区要求此类进项转出，9月1日后全国统一：保险理赔对应进项可正常抵扣。如1-8月已做转出，可更正申报拿回。
2
企业转让子公司股权，中介服务费进项处理
投资/集团 · 黑名单第2项 · 有偿转让股权（高风险）
⛔ 进项须转出 ▾
场景描述
F公司为转让全资子公司100%股权，支付：审计费60万（税额3.6万）、资产评估费40万（税额2.4万）、律师费30万（税额1.8万）、财务顾问费50万（税额3万），合计进项10.8万元。
判定逻辑
有偿转让非上市公司股权 → 属于黑名单第2项 → 为此发生的审计、评估、律师、咨询等中介费进项一律不得抵扣。已抵扣的必须做进项转出，计入长期股权投资成本。
税额计算
审计费进项：3.6万 → 转出 ✗ 评估费进项：2.4万 → 转出 ✗ 律师费进项：1.8万 → 转出 ✗ 顾问费进项：3.0万 → 转出 ✗ 合计须转出：10.8万
⚠ 稽查重点！这是新规落地后最容易被查的类型。立即拉出近12个月股权转让中介费进项明细，已抵扣的全部转出。
3
制造企业收到政府产业扶持资金，采购进项处理
制造业 · 白名单第6项 · 不挂钩的财政补贴
✅ 进项可抵 ▾
场景描述
D公司获得区政府"专精特新"产业扶持资金300万元（文件明确为无偿扶持，与销售额/销量不挂钩）。当月用该资金采购研发设备取得进项税18.2万元。
判定逻辑
关键判定：补贴是否与销售额/销量直接挂钩？
· 不挂钩 → 白名单第6项 → 不征税，但采购进项正常抵扣
· 挂钩（如按出货量每吨补贴X元）→ 属于应税收入，需缴增值税，进项也可抵（但税基不同）
税额计算
财政补贴收入：300万（不征增值税） 采购研发设备进项：18.2万 进项处理：正常抵扣 18.2万 ✓
💡 留存政府补贴文件备查，重点核实文件中是否写明"与销售数量/收入不挂钩"。这是判定白/黑的关键依据。
4
投资公司取得参股企业分红，尽调咨询费进项处理
投资/控股 · 黑名单第3项 · 股息红利
⛔ 进项须转出 ▾
场景描述
G投资公司持有H科技公司30%股权，年度取得股息分红500万元。为该项投资决策，G公司支付：专项尽调费60万（税额3.6万）、行业咨询费25万（税额1.5万）、分红专项审计20万（税额1.2万），合计进项6.3万元。另外G公司日常办公租金进项5万/月。
判定逻辑
持有股权取得股息红利 → 属于黑名单第3项 → 与分红直接相关的专项费用进项不得抵扣。
但：日常通用费用（办公租金、水电、综合管理费用）不直接归属分红业务，可正常抵扣。
税额计算
尽调费进项：3.6万 → 转出 ✗（直接相关） 咨询费进项：1.5万 → 转出 ✗（直接相关） 审计费进项：1.2万 → 转出 ✗（直接相关） 办公租金进项：5万 → 正常抵扣 ✓（通用费用） 合计须转出：6.3万
⚠ 区分"直接相关专项费用"和"日常通用费用"是关键。建议企业按项目单独核算，避免混同后全部被要求转出。
5
供货合同未履约，买方支付违约金，卖方前期备货进项处理
商贸 · 白名单第3项 · 未履约合同违约金
✅ 进项可抵 ▾
场景描述
A商贸公司与B签订800万供货合同，A为此采购专用物料35万（税额4.55万）。后B方原因合同解除（未发货、未开票），B支付违约金80万。
判定逻辑
核心判断：合同是否实际履行？
· 合同未履行、未发货、未开票 → 白名单第3项 → 违约金不征增值税，前期备货进项正常抵扣
· 合同已履行、已发货 → 违约金属于"价外费用"，需计提销项税（性质完全不同）
税额计算
违约金收入：80万（未履约，不征增值税） 前期备货进项：4.55万 进项处理：正常抵扣 4.55万 ✓
💡 务必留存：①解除合同协议 ②未发货/未提供服务证明 ③原合同副本。税务核查时，这些是证明"合同未履行"的关键证据链。
6
外贸企业为境外客户提供服务，对应采购进项处理
外贸 · 黑名单第1项 · 非境内应税交易
⛔ 进项须转出 ▾
场景描述
E外贸公司为东南亚客户提供技术咨询服务，服务完全在境外消费。E公司为此：采购专用设备（税额6万）、支付项目差旅费（税额2.4万）、外包翻译服务（税额0.6万），合计进项9万元。
判定逻辑
服务完全在境外消费 → 不属于增值税法第四条规定的境内应税交易 → 黑名单第1项 → 对应采购进项一律不得抵扣。新规统一了标准，不再区分"完全在境外"或"部分涉及境内"。
税额计算
设备采购进项：6.0万 → 转出 ✗ 差旅费进项：2.4万 → 转出 ✗ 翻译服务进项：0.6万 → 转出 ✗ 合计须转出：9.0万
⚠ 外贸企业重点注意：需建立境外业务台账，将境内/境外业务对应的进项分开核算。共用部分按比例分摊。
7
农产品加工企业收到惠农补贴+保险理赔，综合进项处理
农产品加工 · 白名单第1、6项 · 复合场景
✅ 进项可抵 ▾
场景描述
某农产品加工企业当月发生：
① 收到农业局惠农补助150万（与销量无关）
② 仓库遭暴雨浸泡，保险理赔60万，维修仓库取得进项4.8万
③ 正常采购农产品加工辅料取得进项12万
判定逻辑
① 惠农补助（不与销量挂钩）→ 白名单第6项 → 不征税，但对应进项正常抵扣
② 保险理赔维修 → 白名单第1项 → 进项4.8万正常抵扣
③ 正常采购 → 应税交易，进项12万正常抵扣
税额计算
维修仓库进项：4.8万 → 正常抵扣 ✓ 正常采购进项：12万 → 正常抵扣 ✓ 惠农补助：不征增值税 合计可抵扣：16.8万
💡 农产品企业注意：25号公告不影响农产品收购发票抵扣规则和出口退税规则。收购票仍需保证"三流一致"，出口函调风险依旧严格执行。
8
科技公司无偿为关联公司提供技术服务，对应进项处理
科技/服务 · 白名单第4项 · 无偿提供服务
✅ 进项可抵 ▾
场景描述
M科技公司无偿为关联公司N提供系统运维服务（非金融商品），为此采购运维工具软件（税额2.8万）、支付工程师差旅（税额0.9万），合计进项3.7万元。
判定逻辑
无偿提供服务（不含无偿转让金融商品）→ 白名单第4项 → 不做视同销售，属于非应税行为 → 对应进项无需转出，正常抵扣。
税额计算
软件采购进项：2.8万 → 正常抵扣 ✓ 差旅费进项：0.9万 → 正常抵扣 ✓ 合计可抵扣：3.7万
💡 仅限"无偿提供服务"场景。如果是无偿转让金融商品，则不适用本条。集团内部无偿服务较为常见，注意留存服务协议备查。
9
商贸企业将应收账款转让给保理公司，融资相关进项处理
商贸 · 白名单第5项 · 转让应收账款债权
✅ 进项可抵 ▾
场景描述
C商贸公司将对客户的500万应收账款转让给保理公司融资。此前该笔销售采购商品取得进项32.5万元。保理手续费取得进项1.2万。
判定逻辑
转让自身应税交易产生的应收账款债权（不含有价证券）→ 白名单第5项 → 债权转让行为不征增值税，对应进项正常抵扣。
税额计算
原销售采购进项：32.5万 → 正常抵扣 ✓ 保理手续费进项：1.2万 → 正常抵扣 ✓ 合计可抵扣：33.7万
💡 保理融资、应收账款ABS等场景中常见。注意仅限"因自身应税交易产生的应收债权"，不含以有价证券为基础的债权转让。
10
大宗商品期货公司纯交易结算手续费进项处理
投资/期货 · 黑名单第4项 · 期货非实物交割
⛔ 进项须转出 ▾
场景描述
J贸易公司当月进行大豆期货交易：
① 纯交易结算（平仓对冲）手续费15万（税额0.9万）
② 实物交割采购取得进项11万
③ 交割环节仓储费进项2.2万
判定逻辑
货物期货仅在实物交割环节涉及增值税：
· ① 纯交易结算 → 黑名单第4项 → 进项不得抵扣
· ②③ 实物交割 → 正常应税交易 → 进项正常抵扣
税额计算
交易结算手续费：0.9万 → 转出 ✗ 实物交割采购进项：11万 → 正常抵扣 ✓ 交割仓储费进项：2.2万 → 正常抵扣 ✓ 合计须转出：0.9万 合计可抵扣：13.2万
⚠ 期货公司/大宗商品贸易商需区分两个环节：纯交易结算进项转出，实物交割进项正常抵扣。建议分开核算、分别取得发票。
